Responsive CSS Cheat Sheet

Quick reference guide for modern responsive web design

Media Queries

Conditionally apply CSS styles based on device characteristics like screen width, height, or orientation.

@media (max-width: 768px) {
  .container { width: 100%; }
}

Flexbox Layout

One-dimensional layout system for arranging items in rows or columns with flexible spacing and alignment.

display: flex;
justify-content: center;
align-items: center;

CSS Grid

Two-dimensional layout system for creating complex responsive grid structures with rows and columns.

display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 1rem;

Responsive Typography

Scale text fluidly across devices using relative units and the clamp() function for optimal readability.

font-size: clamp(1rem, 2vw, 1.5rem);
line-height: 1.6;

CSS Filters

Apply visual effects like blur, brightness, contrast, and saturation to elements for enhanced aesthetics.

filter: brightness(1.2) contrast(1.1);
backdrop-filter: blur(10px);

Viewport Units

Responsive units based on viewport dimensions: vw (width), vh (height), vmin, and vmax for fluid sizing.

width: 100vw;
height: 100vh;
font-size: 5vw;

Container Queries

Apply styles based on parent container size rather than viewport, enabling truly modular components.

@container (min-width: 400px) {
  .card { flex-direction: row; }
}

CSS Variables

Define reusable custom properties for consistent theming and easier maintenance across stylesheets.

:root { --primary: #6c5ce7; }
.btn { color: var(--primary); }

Responsive Images

Optimize images for different screens using srcset, picture element, and object-fit properties.

img { max-width: 100%; height: auto; }
object-fit: cover;
